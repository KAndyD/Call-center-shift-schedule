# Проверка сборки

- Среда фактического тестирования: Python 3.13.5, Linux; необходимые научные пакеты указаны в `requirements.txt`.
- Совместимость зависимостей с CPython 3.14 Windows x64 проверена по метаданным дистрибутивов на PyPI. Запуск на физической машине Windows 11 не проводился.
- Проверки: `python -m unittest discover -s tests -v`. Реальный протокол: `results/test_run.txt`.
- В каждой задаче пересчёт ограничений и целевой функции производится отдельным модулем `verify.py` через NumPy.
- Программа `main.py` была выполнена в этой среде; численные результаты и графики сохранены в `results/`.
- Для повторения эксперимента: `python main.py`. Это перезапишет результаты измерений и файлы отчётов внутри папки проекта.
